# 🌐 AWS S3 Static Website Hosting

## 📌 Project Overview

This project demonstrates how to host a static website using AWS S3 with public access and automated deployment using GitHub Actions.

---

## ⚙️ Tech Stack

* AWS S3
* GitHub Actions (CI/CD)
* HTML, CSS

---

## 🚀 Features

* Static website hosting on AWS S3
* Public access configuration using bucket policy
* Automated deployment using CI/CD pipeline
* Simple and responsive UI

---

## 📂 Project Structure

```
.
├── index.html
├── style.css
└── .github/workflows/
    └── s3-deploy.yml
```

---

## ▶️ How It Works

1. Code pushed to GitHub repository
2. GitHub Actions workflow triggers
3. Files automatically uploaded to AWS S3 bucket
4. Website gets updated instantly

---

## 🔧 Deployment Steps

1. Create an S3 bucket
2. Enable static website hosting
3. Configure bucket policy for public access
4. Add GitHub Actions workflow
5. Push code to repository

---

## 💡 Learning Outcomes

* AWS S3 static hosting
* CI/CD pipeline using GitHub Actions
* Cloud deployment basics
* Automation of website updates
